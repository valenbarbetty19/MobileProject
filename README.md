
# Mobile Automation Workshop - WebdriverIO Native App


## How to Run the Project

1. **Open the android emulator and start a session with Appium**
2. **Clone the repository:**
   ```bash
   git clone https://github.com/valenbarbetty19/MobileProject.git
   ```
2. **Setup APK Path:** Open `BaseTest.java` and update the `app` capability with the path to the `.apk` file
3. **Execute via TestNG:**
    * Right-click on the `testng.xml` file in the root directory.
    * Select **Run 'testng.xml'**.
